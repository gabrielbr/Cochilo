# 0.64.0: one night, not two; a day never past 24 hours (four-skill audit)

The owner's screenshot: the Day ring said "25h15m of sleep", Today said "Asleep · 21h 15m". The
hour-by-hour list showed why: "Night sleep · Crib · Since 19:15 · 21h 15m", still running, beside
"Night sleep 19:15–00:28". Both phones had started the night at 19:15. Sync merged two sleeps
for one night: one got its Woke up, and the other stayed open. Today trusted the open one, and the
ring added both.

**How each skill was used.** All four were loaded with the Skill tool earlier in this session,
before the conversation was summarized: `ux-user-flows`, `less-is-more`, `impeccable` (with

`graphic-design-fundamentals`. They were not reloaded for this change. Their checklists were
applied from that reading. No screen changes its layout here, only the number the ring and its
spoken summary show, so no screenshot changed and the existing snapshots still pass.
