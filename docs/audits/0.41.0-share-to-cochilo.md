# Audit: Share to Cochilo (0.41.0)

Date: 2026-11-03 · Auditor: Claude

**Scope.** The owner: "Cochilo doesn't appear in Android's list when sharing… when I export from
Napper I want to share directly to Cochilo so it imports the data."

What changed:
- `MainActivity`: `singleTask`, plus `SEND` and `VIEW` intent filters labelled "Import into
  Cochilo".
- `backup/ShareImport.kt`.
- `MainViewModel.importContent`, shared by file and text imports.

There's no new screen: the outcome is the existing import message.

**Checks.**
- **Fewest taps:** two taps in Napper and none in Cochilo, where it used to take six steps through
  Settings (docs/flows.md, docs/backup.md).
- **Safety:** import never deletes, so there is no confirmation step. Unrelated shares just say
  it isn't a backup, and a share is handled once.
- **Privacy and permissions:** no permission is added (the sender grants read access to that one
  file), and nothing leaves the phone.
- **Copy:** the share label is in English and Portuguese, verb first.
- **§13 and impeccable:** no visual change. The share-sheet label follows the voice ("Import into
  Cochilo" / "Importar no Cochilo").

**Not verified here.** No device: the share sheet and the filters were checked by building, and
`importContent` is the same code that Settings' import runs. Try it once from Napper.
