# Audit: asking no longer crashes (0.39.1)

Date: 2026-11-03 · Auditor: Claude

**Scope.** A bug fix in the model's path:
- `Grounding.fit`;
- `LocalModel.tokens`;
- the VM's lock and crash flag;
- the paused note on Ask.

No layout change, except the paused note (meta text and a secondary button, the patterns already
on Ask), so no new screenshot.

**Root cause.** The 0.38.0 prompt (rules, digest, passages, question) could pass the model's
1280-token window. MediaPipe aborts natively on overflow, which can't be caught.

**Checks.**
- §13: the paused note follows the existing note style. Meta role, no new colour, a 48dp button.
- impeccable: visibility of system status improves (the app says why the AI is off); error
  prevention, on three fronts: fit, lock, pause.
- No permission or data change.

**Not verified here.** No phone was attached: the native crash itself wasn't reproduced. The fix
removes the overflow and the concurrency paths that cause it. If a phone still crashes, the pause
stops it repeating.
