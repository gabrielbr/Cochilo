# 0.63.0: share a playlist to Cochilo (four-skill audit)

The owner asked: "When user shares a playlist from their Spotify/YouTube Music, they should be
able to share directly to Cochilo, so it adds to the playlist."

**How each skill was used.** All four were loaded with the Skill tool earlier in this session
(this conversation): `ux-user-flows`, `less-is-more`, `impeccable` and
`graphic-design-fundamentals`. Their checklists were applied to this flow. Nothing new is drawn:
the only UI is a share-sheet entry and the existing message bar with Undo. No new screenshot was
needed; the existing ones are unchanged.

## 1. ux-user-flows
**Entry.** The Android share sheet from the music app. The entry is now labelled "Add to Cochilo".
It used to be "Import into Cochilo", which would mislead for a playlist.

**Branches:**
- added, with Undo;
- already there;
- full (five);
- not a music link (goes to the import, as before).

**Taps:** saving a link went from 5 to 2 (flows.md).
