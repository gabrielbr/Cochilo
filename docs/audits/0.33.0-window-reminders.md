# Audit: window reminders (0.33.0)

Date: 2026-11-03 · Auditor: Claude (impeccable critique, native; graphic-design-fundamentals §13)

## Scope

The owner's request: notifications 30 and 15 minutes before each sleep window, to start the
preparation. `domain/Reminders.kt` (`RemindersTest`), `notify/SleepReminders.kt`, the receiver's
REMIND and START_ROUTINE, `Entries.logRoutine`, `Prefs`, Settings' `ReminderRows`. No new
components or tokens (SwitchRow, FilterChips), so no design-system patch. Screens looked at:
`reminders_settings_ptBR_light`; the notification itself is Android's standard layout.

## Decisions

| Question | Choice | Why |
|---|---|---|
| Before what? | `windowStart`, the window opening | "30/15 minutes before each window" |
| Sound? | Its own channel at default importance | It must reach someone across the room; the live notification stays silent; Android lets her silence just this channel |
| Exact alarm? | No: `setAndAllowWhileIdle` | No new permission; a few minutes of slack is fine for a 15-minute heads-up |
| Late reminder? | Dropped after 10 min | A late nudge is noise, never guilt |
| Night? | Quiet 21:00–06:00 | Night wakings aren't "windows" |
| What button? | Start routine (logs it) | The point is to start preparing; one tap from the shade |
