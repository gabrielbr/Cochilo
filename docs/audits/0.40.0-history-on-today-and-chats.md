# Audit: History on Today, and Ask's chats (0.40.0)

Date: 2026-11-03 · Auditor: Claude (impeccable critique, native; graphic-design-fundamentals §13)

## Scope

Two asks from the owner:
- Move History into Today's recent items ("we don't need both"), keeping the filters.
- Let the user create several chats with Ask, one per topic.

What changed:
- `HistoryDays`, Today's "Day by day" section, and three tabs instead of four.
- `data/Chats.kt` (`ChatStore`, `ChatStoreTest`), `ChatsScreen`, and frozen answers
  (`AskExchange.parts`, `toItem`, `toExchange`).
- The "Chats" row on Ask.

No new components or tokens: Button, ListRow, RowGroup, IconButton and FilterChips. `gg_ic_close`
is from the design system's line set. So there is no design-system patch.

Screens looked at:
- `today_light`, `today_tablet_light`, `history_light` (the days part), `history_font200_light`,
  `history_foldable_dark`, `chats_ptBR_light`;
- every tab-bar screenshot (32 re-recorded).

## What failed first, and the fix

| Found | Fix |
|---|---|
| Today's own timeline and list were also the first day of History: the same day shown twice | Today's day-by-day section replaces both; today is its first day |
| A saved chat would re-run its answers against today's numbers | Answers are frozen when shown (`parts`) |
| An unused new chat would clutter the list | A chat is saved only from its first question |
| Deleting needed a confirmation | Undo instead, at the top of the list |
