# Audit: the on-device AI downloads itself (0.37.0)

Date: 2026-11-03 · Auditor: Claude (impeccable critique, native; graphic-design-fundamentals §13)

## Scope

The owner: the Gemma download was "terrible UX"; the app should download it when the parent
decides to use it. Before, the family build asked her to find the file on Hugging Face (behind a
sign-in and the Gemma terms), download 550 MB in a browser, and pick it in the app.

What changed:
- `ai/ModelDownload.kt` (tested in `ModelDownloadTest`).
- The github `ModelSources` now uses Android's download manager, waits for Wi-Fi, verifies the
  SHA-256, and keeps file import as a fallback.
- `ModelState` gains Wi-Fi waiting, copying, and two new failure reasons.
- The sheet's new states, and Ask's offer under a "not sure" reply.
- The **Publish assistant model** workflow, and the Release workflow now takes the Play pack's
  model from the same pre-release.

No new components or tokens: Button, ListRow, RowGroup and ProgressLine. So there is no
design-system patch.

Screens looked at:
- `model_sheet_app_download_light`, `model_sheet_app_downloading_light`,
  `model_sheet_waiting_wifi_ptBR_light`;
- `model_sheet_play_light`, `model_sheet_ready_ptBR_dark`;
- `ask_not_sure_light`.

## Decisions

| Question | Choice | Why |
|---|---|---|
| Where from? | A pre-release of this repository | Hugging Face's Gemma file is gated (a 401 without a signed-in token); a pre-release is public, and self-update ignores it |
| How? | Android's download manager | Background, resumable, a system progress notification, no new permission |
| Network | Wi-Fi only, "Download now on mobile data" when it's waiting | 550 MB on a data plan is a cost she should choose |
| Trust | The published SHA-256, checked before use | Same standard as self-update |
| Where is it offered? | Settings, and under a reply the list couldn't give | "When the user decides to use it": the moment she asks something new |
| Before it's published | "The model isn't ready to download yet. You can choose a file instead." | Honest, with a way forward |
| Licence | One line in the sheet; `GEMMA-NOTICE.txt` on the release | Gemma's terms ask for the notice to travel with it |

## What failed first, and the fix

| Found | Fix |
|---|---|
| The file-import copy step would need twice the space (download and then copy). | The download stays in the app's own external folder, which other apps can't read, so it's never copied. |
| Download-and-copy had one set of words. | `copying` keeps "Copying…" for a chosen file, and downloads say "Downloading…". |
