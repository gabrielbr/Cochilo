# Audit: tablets and foldables (0.25.0)

Date: 2026-11-03 · Auditor: Claude (impeccable critique, native; graphic-design-fundamentals §13)

## Scope

`ui/kit/Shell.kt` (AppShell, NavRail, TwoPanes, WidthClass); the root and the screenshot
harness use it. Design system 0.21.0: four size tokens and the Navigation rail.

Screens looked at: `today_tablet_light`, `patterns_tablet_light` (800dp), `today_foldable_light`,
`history_foldable_dark`, `settings_foldable_light` (841dp). Every phone screenshot is unchanged.

## Found while building (fixed before release)

| # | Severity | Issue | Fix |
|---|---|---|---|
| 1 | Important | An 841dp foldable stayed on one pane: the class was taken from the space inside the 4dp frame (833dp) | The class follows the window's width, as Android defines it |
