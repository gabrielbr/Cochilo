# Audit: seamless fabrics (0.26.0)

Date: 2026-11-03 · Auditor: Claude (impeccable critique, native; graphic-design-fundamentals §13)

## Scope

The eleven texture tiles remade by `scripts/seamless_tile.py`; `fabricBrush` repeats them instead
of mirroring. Design system 0.21.1 carries the same tiles. Screens looked at:
`today_fabric_balao_light`, `today_sleeping_fabric_tropical_dark`, `fabric_picker_ptBR_light`,
`settings_light`, and a 2×3 repeat contact sheet of every tile.

## Found while building (fixed before release)

| # | Severity | Issue | Fix |
|---|---|---|---|
| 1 | Important | A plain repeat showed each photo's light falloff as lighter and darker blocks (Chumbo, Mel) | Light flattened by dividing by a very soft blur, keeping the mean colour |
| 2 | Polish | A bright fold at Chumbo's photo edge showed on every seam | A 5% border is trimmed before blending |
