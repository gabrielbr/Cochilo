# Audit: locked backups (0.23.0)

Date: 2026-11-03 · Auditor: Claude (impeccable critique, native; graphic-design-fundamentals §13)

## Scope

Settings › Data › Protect backups (a row and a sheet), the "This backup is locked" sheet on
import, and the sealed file format (`backup/Sealed.kt`). No new components or tokens: the sheets
compose Sheet, Field and Button, so there is no design-system patch.

Screens looked at: `passphrase_sheet_light`, `unlock_sheet_wrong_ptBR_dark`.

## graphic-design-fundamentals (§13 checklist)

| # | Question | Result |
|---|---|---|
| 1 | Brief | Pass: a file that leaves the phone can't be read; export stays one tap |
| 2 | Concept | Pass: "locked / trancado", a plain everyday metaphor, no jargon (no "encryption" in the app) |
| 3 | Hierarchy | Pass: title, one line of why, the field, the warning, then one teal Save |
| 4 | Contrast | Pass: body muted on page and ink on surface already pass in all three themes |
| 5 | Alignment and grid | Pass: one column, the sheet's 24dp inset |
| 6 | Spacing | Pass: space4 between line and field, space6 before the actions, as other sheets |
| 7 | Typography | Pass: meta under the field; sentence case; verb-first buttons |
| 8 | Colour | Pass: one mint action; the wrong-passphrase line is ink, not an alarm colour |
| 9 | Consistency | Pass: same shape as the Routine steps and baby sheets |
| 10 | Simplicity | Pass: one field, shown as typed, instead of type-twice |
| 11 | Real-size test | Pass: Pixel 5, light and dark, English and Portuguese |
| 12 | Accessibility and ergonomics | Pass: the field has its label; the wrong line is a live region; 48dp buttons |
| 13 | Production | Pass: unit tests for round trip, wrong passphrase, tampering, uniqueness, strength |

**13/13.**

Fixed during the audit: the first draft said "encrypted" in the row's meta. It became "locked", in
the brand voice (quiet and short).
