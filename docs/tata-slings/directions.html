Cochilo, mais dela

Today Cochilo is navy lines on cream: calm, but cold and a little masculine. Three directions to make it warmer and more hers. All three keep the Tatá Slings brand (teal mark, Libre Franklin) and every rule we have: icon always beside its word, one teal action per screen, contrast checked. The colours come from her own fabrics (Rosa Chá, Lavanda, Mel, Trevo, Amora, Cereja), so the app looks like the slings.

Each phone shows the same moment: the Log button open, finger on Feed › Right.

What any of them changes in the code: the design system gets the new colour roles and the icon set first (brand tata-slings), then CTokens.kt is regenerated here; the icons move from one-colour lines to two layers (line + soft fill), each kind in its fabric colour. The timeline's data colours move to the same fabric family, re-checked so the eight kinds are still told apart (and always next to a word).

Icon sources looked at: Phosphor duotone (MIT), IconPark TwoTone (Apache 2.0), Tabler (MIT, lines only), Fluent Emoji flat (MIT, illustrated). None has a diaper, a breast pump and a sling together, so the proposal is our own set: the shapes we already have, given a fill layer, all under the design system's licence.
