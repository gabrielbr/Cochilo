# Tatá Slings textures

Her fabrics, cropped from the product photos on tataslings.com.br (2026-11-02): fabric only, no
label, seam, face or hand. 384 × 384 px WebP (quality 78), true repeating tiles (since
0.21.1: border trimmed, light flattened, blended with a half-offset copy; Cochilo's
`scripts/seamless_tile.py`), drawn repeated, so prints repeat like cloth instead of mirroring. © Tatá Slings; used in Cochilo with the owner's permission. Not for other
apps.
